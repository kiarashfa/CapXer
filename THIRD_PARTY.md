## Fonts

Both fonts are served from CapXer itself, so no third-party font server is contacted. Figtree sets the interface and reading text, and JetBrains Mono sets numbers and measurements. They are packaged by [Fontsource](https://github.com/fontsource/fontsource) (MIT).

| Font | License | Source |
| --- | --- | --- |
| Figtree | OFL-1.1 | [erikdkennedy/figtree](https://github.com/erikdkennedy/figtree), through `@fontsource-variable/figtree` |
| JetBrains Mono | OFL-1.1 | [JetBrains/JetBrainsMono](https://github.com/JetBrains/JetBrainsMono), through `@fontsource-variable/jetbrains-mono` |

The social card generator in `scripts/brand` keeps its own copy of Figtree (`scripts/brand/fonts/figtree-variable.woff2`) to draw the card image. That copy is not served by the site, and its license is in `scripts/brand/fonts/FONT-LICENSES.txt`.

## Data and services

| Name | Used for | Terms |
| --- | --- | --- |
| Google Analytics 4 | Visit statistics, only after consent | [Google Analytics Terms of Service](https://marketingplatform.google.com/about/analytics/terms/us/) |
| Google Drive | Optional cloud save in the visitor's own Drive (a hidden app folder), with Google's sign-in script loaded from accounts.google.com only when needed | [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy) |
| Dropbox | Optional cloud save in the visitor's own Dropbox (the app's own folder) | Dropbox Terms of Service |

No third-party dataset is included. The camera database in `src/data/` is CapXer's own: each sensor size is taken from the maker's published specifications or from a SMPTE standard, and every value cites its source in `src/references/references.json`. The sources are listed on the website's About page.
